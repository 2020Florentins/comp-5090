## 起動の手順

1. チャット-1（実行役）：このフォルダで Claude Code を開き、`/loop LOOP_PROMPT.md を読み、その手順で 1 ステップ進めてください`（間隔は指定せず、自分でペースを決めさせる）
2. チャット-2（監視役）：**別のセッション**を、同じフォルダで開く
   - 1 回だけ確認：`MONITOR_PROMPT.md を読み、その手順で 1 回監視してください`
   - 2 時間おき：`/loop 2h MONITOR_PROMPT.md を読み、その手順で 1 回監視してください`（このセッションを開いている間だけ動く）
3. 止めたいとき：HALT.md を作る（本人でもチャット-2 でも可）。再開は HALT.md を削除する。

## git とクラウドの監視（2026-10-22 追加）

## 注意
- 無人での起動（タスクスケジューラなど）は、自動判定に拒否されたままのため設定していない。監視役の定期実行は、セッションを開いている間のみ。
- 費用が発生する操作は、どのチャットでも一切しない（SCOPE.md の範囲外）。
